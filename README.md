# Sani Kumar Portfolio

This is a static portfolio website built with HTML, CSS, and vanilla JavaScript. It has no build step.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the repository root whenever changes are pushed to `main`.

1. In the repository settings, open **Pages** and set the source to **GitHub Actions**.
2. Push changes to `main`.
3. Check the **Actions** tab for a successful **Deploy portfolio to GitHub Pages** run.
4. The site will be available at `https://sunnyrebel286.github.io/Portfolio/`.

Add the optional profile photo at `assets/images/profile.jpg` and resume at `assets/documents/Sani_Kumar_Resume.pdf` to show those links on the website.
